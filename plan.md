Мини-проект: API → обработка → CSV/SQLite

Используй:

requests — забрать JSON из API;
json — понять работу с JSON руками;
pathlib — файлы/папки;
datetime — даты;
logging — нормальные логи вместо print;
pandas — преобразования;
sqlite3 — сохранить результат в БД.

Структура примерно:

mini_etl/
├── main.py
├── data/
│   ├── raw/
│   └── processed/
└── logs/

Само задание:

Забрать данные из какого-нибудь публичного API.
Проверить HTTP-код и обработать ошибку через try/except.
Сохранить исходный JSON как есть в data/raw/.
Превратить данные в DataFrame.
Почистить:
переименовать столбцы;
убрать ненужные;
обработать None;
привести типы.
Сделать хотя бы одну агрегацию через groupby.
Сохранить результат:
в CSV;
в SQLite.
Записать через logging:
когда загрузка началась;
сколько строк пришло;
сколько осталось после обработки;
успешно ли сохранилось;
ошибку, если что-то упало.
